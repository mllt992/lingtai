# 回归用例 · 启动白屏（scoped CSS :global 选择器）

- **关联 BUG**：`docs/03_问题记录/20260916_启动空白.md`
- **创建日期**：2026-09-17
- **目的**：防止 Vue scoped 样式再次把规则打到 `html` 上导致整页 display:none

---

## 用例 1 · mini 启动必须可见

| 步骤 | 操作 | 期望 |
|---|---|---|
| 1 | `config.json` 设 `ui.windowMode = "mini"`，启动 Loft | 主窗口出现，非纯白 |
| 2 | 观察标题栏 | 显示「凌台 · Loft」，高度约 32px，无「桌面控制台」副标题 |
| 3 | 观察顶栏 | MiniNav 图标 Tab 可见、可点击 |
| 4 | 观察主体 | 当前路由页面有内容（启动器至少有标题/搜索框） |

**失败特征**：整窗纯白；DevTools 中 `getComputedStyle(document.documentElement).display === "none"`。

## 用例 2 · 展开模式回归

| 步骤 | 操作 | 期望 |
|---|---|---|
| 1 | 点击标题栏「展开」 | 窗口变大，出现左侧 Sidebar |
| 2 | 标题栏 | 副标题「桌面控制台」重新出现，高度约 38px |
| 3 | 各页面 | 布局恢复正常密度（非 mini 压缩） |

## 用例 3 · 静态检查（提交前）

在仓库根目录执行，**必须 0 命中**：

```bash
rg ":global\(html\[data-ui-mode='mini'\]\)\s+\." src
```

若命中，说明又写成了「`:global` 只包 html、后代选择器在外」的危险形式。

正确写法应为：

```css
:global(html[data-ui-mode='mini'] .child) { ... }
```

或放到全局 CSS（如 `src/styles/main.css`）中直接写：

```css
html[data-ui-mode='mini'] .child { ... }
```

## 用例 4 · 运行时尺寸探针（可选，调试用）

启动后通过 WebView2 CDP / DevTools 执行：

```js
getComputedStyle(document.documentElement).display // 必须 "block"
document.querySelector('.app-shell').getBoundingClientRect().width // 必须 > 0
```
