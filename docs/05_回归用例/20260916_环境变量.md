# 回归用例 · 环境变量

来源：`docs/02_功能设计/环境变量_实施方案_20260916.md` §11

手工在 Windows 上执行。测完删除测试变量 `LOFT_TEST`。

| 编号 | 步骤 | 预期 | 优先级 |
|---|---|---|---|
| TC-ENV-001 | 点侧栏「环境变量」 | 进入列表页 | P0 |
| TC-ENV-002 | 观察默认 chip | 用户、系统勾选，进程未勾 | P0 |
| TC-ENV-003 | 看任意一行 | 无单元格渲染变量值 | P0 |
| TC-ENV-004 | 点复制，记事本粘贴 | 与注册表原值一致 | P0 |
| TC-ENV-005 | 写备注，重启凌台 | 备注仍在 | P0 |
| TC-ENV-006 | 新增用户 `LOFT_TEST=hello`，再删除 | 系统属性可见；删除后消失 | P0 |
| TC-ENV-007 | 未提权改系统级，UAC 点取消 | 变量不变，提示「已取消提权」 | P0 |
| TC-ENV-008 | 未提权改系统级，UAC 同意 | 写入成功，列表刷新 | P0 |
| TC-ENV-009 | 编辑用户 Path，加一条再保存 | 注册表 Path 含该段 | P0 |
| TC-ENV-010 | 进程档新增 `LOFT_PROC=1`，重启凌台 | 重启后该变量不在 | P1 |
| TC-ENV-011 | 删除 Path，点取消 | Path 仍在 | P0 |
| TC-ENV-012 | 备注含「代理」，搜「代理」 | 仅匹配行留下 | P1 |
| TC-ENV-013 | 断网无关；注册表异常时点重试 | 错误条 + 可重试 | P1 |
| TC-ENV-014 | 已有 LOFT_TEST 再新增同名 | 确认覆盖后值被替换 | P1 |
| TC-ENV-015 | 复制含 `%SystemRoot%` 的项 | 粘贴未展开字符串 | P1 |
| TC-ENV-016 | Mini 模式下打开本页 | 顶栏可换行，三档 chip 仍可点 | P1 |
