# 回归用例 · 性能监控（卡死修复）

来源：`docs/03_问题记录/20260917_BUG_性能监控页面卡死.md`

手工在 Windows 上执行。重点验证：轮询路径不再拉起 PowerShell，UI 不卡死。

| 编号 | 步骤 | 预期 | 优先级 |
|---|---|---|---|
| TC-REG-MON-001 | 进入「性能监控」，停留 ≥30s；同时开任务管理器 | 无频繁 `powershell.exe`；UI 可点击；CPU/内存折线持续更新 | P0 |
| TC-REG-MON-002 | 监控页停留期间切到启动器再切回 3 次 | 无卡死、无报错 | P1 |
| TC-REG-MON-003 | 设置刷新间隔为 2000ms，保存后回监控页 | 按 2s 刷新，无请求堆积 | P1 |
| TC-REG-MON-004 | 监控页点「刷新磁盘」 | 磁盘列表刷新，无卡顿 | P1 |
| TC-REG-MON-005 | 观察托盘 tooltip / 数据面板 | CPU/内存指标仍每 2s 更新，不被监控页拖死 | P1 |
| TC-REG-MON-006 | GPU 卡片区（无 NVML 构建） | 显示适配器名称；使用率可为「—」，但不因查询导致卡顿 | P1 |
