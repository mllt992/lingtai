# 2026-09-16 启动空白

## 现象
Mini 双模式改完后，主窗口纯白空白。截图见 loft-window.png / loft-window2.png / loft-window3.png。

## 复现步骤
1. `pnpm tauri:dev`（或直接跑 `src-tauri/target/debug/loft.exe`，Vite 需在 127.0.0.1:1620）
2. 配置 `config.json` 中 `ui.windowMode = "mini"`
3. 观察主窗口：整窗纯白，无标题栏 / 导航 / 内容

## 期望行为
主窗口显示 TitleBar + MiniNav + 业务页面

## 实际行为
纯白窗口。boot.log 显示 `url=http://127.0.0.1:1620/#/launcher`，说明脚本已执行、路由已跳转，但画面无内容。

## 影响范围
- 所有进入 mini 模式的主窗口（默认即 mini）
- 展开模式不受影响（`html[data-ui-mode='expanded']` 没有对应错误规则）
- 与主题无关

## 出现频率
必现（mini 模式）

## 早期误判（已排除）
- ~~WebView 未连上 dev server（IPv6 ::1）~~：127.0.0.1 绑定后 boot.log URL 正确，仍白屏
- ~~CSS 主题 / 布局~~：DOM 完整，只是 0 尺寸
- ~~backdrop-filter 合成崩溃~~：不是根因

---

## 根因分析

### 一句话结论
Vue 3 scoped CSS 把

```css
:global(html[data-ui-mode='mini']) .sub { display: none; }
```

错误编译成打在 `html` 上的：

```css
html[data-ui-mode='mini'] { display: none; }
```

导致 mini 模式下整个文档树 `display: none` → 宽高 0 → 白屏。

### 证据（WebView2 CDP）
- DOM 完整（app.innerHTML ~24KB，TitleBar / MiniNav / 视图都在）
- `getComputedStyle(html).display === "none"`
- `.app-shell.getBoundingClientRect()` 全 0
- matched CSS rules 里 `html[data-ui-mode="mini"] { display: none }` 来自 TitleBar 的 `.sub` 规则

### 触发条件
- `html` 带 `data-ui-mode="mini"`
- 任一 SFC scoped 样式写了 `:global(html[...]) .child`（`:global` 只包了前半截）

### 为什么之前没发现
- 旧版没有 mini 模式，html 上没有 `data-ui-mode`
- 展开模式没有对应错误规则，不会触发 `display:none`
- vue-tsc / vite build 通过，编译期无告警
- boot.log 只记 URL / visible，看不到布局尺寸

### 相似代码
全仓共 39 处同类写法，分布在：
TitleBar / LauncherView / ResourcesView / MonitorView / PortsView / SettingsView / EnvView

---

## 修复方案

将

```css
:global(html[data-ui-mode='mini']) .child { ... }
```

改为把**整条选择器**包进 `:global()`：

```css
:global(html[data-ui-mode='mini'] .child) { ... }
```

### 涉及文件
| 文件 | 处数 |
|---|---|
| `src/components/TitleBar.vue` | 4（含致命的 `.sub { display:none }`） |
| `src/views/LauncherView.vue` | 5 |
| `src/views/ResourcesView.vue` | 4 |
| `src/views/MonitorView.vue` | 5 |
| `src/views/PortsView.vue` | 4 |
| `src/views/SettingsView.vue` | 6 |
| `src/views/EnvView.vue` | 7 |

### 副作用
无业务逻辑变更。mini 密度样式恢复正常生效（标题栏 32px、隐藏副标题等）。

---

## 修复结论

| 项 | 内容 |
|---|---|
| 根因 | Vue scoped CSS `:global()` 只包前半截选择器，把子元素规则打到 `html` 上 |
| 修复方式 | 整条选择器包进 `:global(...)` |
| 影响范围 | mini 模式 UI 渲染；展开模式 / 业务逻辑 / Rust 不变 |
| 同类排查 | 已全仓 grep，39 处全部改完 |
| 验证 | CDP：`html` display=block，shell 551×544，标题栏 32px；截图可见完整 UI |
