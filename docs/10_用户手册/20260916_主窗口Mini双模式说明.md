# 主窗口 Mini 双模式说明

打开凌台后，主窗口默认是贴在屏幕右下角的小面板，不挡中间的工作区。需要大一点时，点标题栏的展开按钮即可。

## 标题栏按钮（从左到右）

- **展开 / 折叠**：小窗与完整控制台来回切。展开后左侧导航会回来；折叠后变成顶栏图标。
- **图钉**：把窗口钉在最前。再点一次取消。默认不置顶。
- **最小化**：收到任务栏。
- **最大化**：仅展开模式可用。小窗没有这一项。
- **关闭**：隐藏到托盘，不是退出。托盘左键可再打开。

## 记住什么

关掉再开，会记住：当前是小窗还是展开、有没有置顶、以及两种尺寸各自被拖到的位置。

## 五个模块

启动器、资源归纳、性能监控、端口监控、设置在小窗里都能用。小窗里「添加应用」会铺满当前窗口；展开后仍是原来的大对话框。

## HUD

屏幕右上角的 CPU / 内存条是独立窗口，和主窗口的大小无关。右键可隐藏，托盘菜单「切换数据面板」可再打开。
