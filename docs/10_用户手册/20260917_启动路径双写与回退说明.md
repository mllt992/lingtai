# 启动路径双写与回退 · 用户手册

> 适用版本：v0.1.0+（路径双写功能）

---

## 这是什么？

启动项和资源现在可以同时记住：

1. **绝对路径**（和以前一样）
2. **相对路径**（相对你在设置里配置的「路径根目录」）

当绝对路径失效（例如移动硬盘换盘符、同步盘换机、目录整体搬家），但相对路径还能拼出新位置时，软件可以：

- 用新位置**继续启动/打开**
- 问你**要不要把绝对路径修好**（或在设置里打开自动修复）

**注意**：只修复主路径。已缓存的应用图标 `iconData` 不会被自动改写；`.lnk` 的目标/图标信息会在修复成功后重新解析一次。

---

## 怎么用

### 1. 配置路径根目录

进入 **设置 → 路径根目录**：

- 输入路径后点「添加根目录」，或点「浏览…」选文件夹
- 常见例子：
  - `D:\Portable`（便携软件库）
  - `C:\Users\<你>\Tools`
  - 同步盘上的工具目录

可配置多个根。若某路径同时落在多个根下，会按**更长（更具体）的根**计算相对路径。

### 2. 添加启动项 / 资源

拖入或手动添加时，若路径在某个根之下，会自动写入相对路径。  
不在任何根下时，行为与旧版相同（只有绝对路径）。

### 3. 启动时发生什么

| 情况 | 行为 |
|---|---|
| 绝对路径存在 | 直接启动 |
| 绝对失效，相对可用 | 默认弹窗：**修复并打开 / 仅本次打开 / 取消** |
| 开了「自动修复路径」 | 静默把绝对路径改成新位置并打开 |
| 两者都失效 | 提示「路径失效，且无法通过相对路径恢复」 |

### 4. 列表健康状态

进入启动器或资源页会异步检测：

- 角标 **红点**：路径失效
- 角标 **黄点**：绝对路径失效，但相对路径可用
- 右键 → **修复路径**（黄点时可用）

### 5. 回填相对路径

已有条目是旧数据、没有相对路径时：

**设置 → 路径根目录 → 回填相对路径**

只会在能匹配到根的条目上写入 `relPath`/`rootHint`，不会删除已有字段。

### 6. 自动修复开关

**设置 → 路径根目录 → 自动修复路径**

- **关闭（默认）**：启动时询问
- **开启**：检测到「相对可用、绝对失效」时自动写回，并在打开时直接使用新路径

---

## 边界说明

- 网址资源不参与检测与回退
- 相对路径含 `..` 的不会被采用
- UNC 根目录（`\\server\share\...`）允许配置；是否可达取决于网络
- 根目录本身被挪走时：会尝试其它已配置的根 + 相对路径
