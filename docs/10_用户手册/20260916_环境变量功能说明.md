# 环境变量 · 使用说明

- 日期：2026-09-16
- 适用版本：凌台 Loft v0.1+

---

## 入口

左侧导航（展开模式）或顶部图标栏（Mini 模式）点 **环境变量**。

## 列表

- 左列：变量名称 + 范围徽章（用户 / 系统 / 进程）
- 右列：备注，失焦即保存，只存在凌台本机
- **列表不显示变量值**，避免肩窥。需要值时点复制。

顶栏可勾选范围。默认 **用户 + 系统**。至少保留一档。

搜索同时匹配名称和备注，不按值搜。

## 复制

行内复制按钮或右键「复制值」：把该范围下的**注册表原值**写入剪贴板（含 `%SystemRoot%` 这类未展开写法）。右键也可只复制名称。

## 新增 / 编辑 / 删除

- **用户**：写入当前用户环境变量，长期有效。
- **系统**：写入系统环境变量。未以管理员运行时会弹出 UAC；取消则不改。
- **当前进程**：只改凌台自己，关掉就没了。

`Path` / `PATH` 编辑时按条目拆开：可增删、上下移动，保存时用 `;` 拼回。

删除 `Path`、`ComSpec` 等关键名会二次确认。把 Path 保存成空也会再问一次。

## 生效说明

改用户 / 系统后，**已经打开的终端、IDE 通常要重开**才会读到新值。凌台自己的「进程」列表也不会自动跟着变。

从凌台启动器拉起的外部程序仍走系统 shell，不会带上你只加在「进程」档里的临时变量。

## 数据位置

备注：`%APPDATA%\com.loft.app\env-notes.json`

真正的环境变量在 Windows 注册表，不在凌台配置里。
